=====================================================================================================
3. COMO CONTINUAR EM OUTRA MÁQUINA / SESSÃO
=====================================================================================================
1. git fetch origin && git switch questoes-juridicas && git pull
2. Colocar em docs/ (raiz do projeto, FORA do Git, nunca commitar) os PDFs: 02 (Dir. Adm., aulas 00–09) e 04 (Dir. Const.,
   aulas 00–18), mais docs/indice_topicos_curso.xlsx. (Espanhol já está concluído.)
   Cache de texto: PYTHONIOENCODING=utf-8 pipeline/.venv/Scripts/python pipeline/extract.py --only 02  (e --only 04)
   (em Linux/Mac use python3 no lugar de pipeline/.venv/Scripts/python).
3. Ver o que falta: validate_content.py --coverage --stage full --subject direito-administrativo (e direito-constitucional).
4. Rodar um agente (Claude Code) por faixa pendente, por exemplo:
     "Leia pipeline/briefs/content.md e produza as questões AOCP dos trechos SEM questões de direito-administrativo a07–a09
      (use inspect_aula.py para ver as páginas de cada trecho no cache). Grave o arquivo a cada aula, valide com
      validate_content.py <arquivo>, não faça git, não mexa no bizu nem em trechos que já têm questões, nem nos
      pontos listados nas seções 11–14 de PROGRESSO-AUDITORIA.txt."
   Faixas sugeridas: Dir. Adm. a07–a09 (25 trechos) · Dir. Const. a09 + a13 (10) · Dir. Const. a16–a18 (~10).
5. Validar cada aula, commitar (git add content/items PROGRESSO-COLABORADOR-ETAPA2.txt; git commit; git push -u origin
   questoes-juridicas).
6. Ao terminar: validação geral (--coverage --stage full nas 3 disciplinas), pytest pipeline/tests -q (inclui teste de
   originalidade; exige o cache de texto), preencher a seção 5 abaixo e fazer o commit/push final.

Regras do trabalho (resumo; íntegra em pipeline/briefs/content.md e INSTRUCOES-COLABORADOR-ETAPA2.md):
  5 alternativas (A–E); mín. 8 questões/trecho (5 se < 6 págs.); dificuldade ~25/50/25%; gabarito por arquivo com cada letra
  entre ~14–26% e máx. 3 seguidas; correta não sistematicamente a mais longa; "incorreta/exceto" ≤ 20%; nenhuma sequência
  de 10 palavras iguais ao PDF (validador rejeita; em lei seca, troque verbos/ordem e quebre listas); explanation ≥ 2 frases;
  pageRef dentro do trecho; "literal": true só para citação exata de norma. Escrever somente em content/items/<disciplina>/.
  Não rodar segment.py, build_catalog.py, build_complements.py, edital_map.py nem o seed.
