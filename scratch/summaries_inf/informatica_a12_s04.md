##### informatica/a12/s04
Este trecho mostra a anatomia de uma janela do Windows 11, tomando o Explorador de Arquivos como modelo: barra de título e botões de controle, faixa de opções (a parte mais cobrada), barra de endereço com seus botões de navegação e caixa de pesquisa.

### Janela e abas

O Windows ("janelas") exibe tudo em janelas. O Explorador de Arquivos passou a ter **abas**, como um navegador: várias pastas na mesma janela, com **Ctrl + T** abrindo uma nova aba e **Ctrl + W** fechando a aba atual. Isso reduz a quantidade de janelas abertas.

### Barra de título e botões de controle

Fica no topo da janela e mostra o nome da pasta ou do aplicativo, com o ícone do programa à esquerda e, no Explorador, as abas. No canto direito ficam os três botões de controle:

| Botão | O que faz | Atalho |
| --- | --- | --- |
| **Minimizar** | Recolhe a janela para a barra de tarefas, sem fechar o programa | Windows + seta para baixo |
| **Maximizar** | Amplia a janela para ocupar a tela inteira | Windows + seta para cima |
| **Restaurar** | Aparece no lugar do Maximizar quando a janela já está maximizada e devolve o tamanho anterior | Windows + seta para baixo |
| **Fechar** | Encerra a janela ou o aplicativo; some também da barra de tarefas | Alt + F4 |

- Clicar com o botão direito num espaço vazio da barra de título, ou usar **Alt + Espaço**, abre o menu de controle (mover, redimensionar, fechar).
- Arrastar a barra move a janela, inclusive para outro monitor; ao arrastar para uma borda da tela, o recurso **Snap Layouts** sugere como dividir o espaço com outras janelas. Duplo clique na barra alterna entre maximizada e restaurada.
- A barra respeita o tema claro ou escuro do sistema.

> ⚠️ Pegadinha: **Alt + F4** fecha o item ativo ou sai do aplicativo (e abre a janela de desligamento quando não há aplicativo ativo); **Alt + Tab** alterna entre janelas; **F2** renomeia; **F10** ativa a barra de menus; **Ctrl + Z** desfaz.

### Faixa de opções (Ribbon)

É a área de comandos agrupados em abas ou guias temáticas (por exemplo, Página Inicial, Compartilhar e Exibir). No Windows 10, o Explorador tinha a faixa expansiva, com várias guias. No Windows 11 ela foi substituída por uma **barra de comandos compacta**, com ícones simplificados na horizontal, mais limpa e adequada tanto ao mouse quanto ao toque. Os principais botões:

| Botão | Função |
| --- | --- |
| **Novo** | Cria pasta, atalho ou outro item no diretório atual (pasta nova: Ctrl + Shift + N) |
| **Recortar / Copiar / Colar** | Mexem na área de transferência (Ctrl + X, Ctrl + C, Ctrl + V) |
| **Renomear** | Altera o nome do item selecionado (F2) |
| **Compartilhar** | Manda o item a outras pessoas, via e-mail, apps ou a rede local |
| **Excluir** | Leva o item à **Lixeira**, de onde ainda dá para recuperá-lo |
| **Classificar** | Muda a ordem dos itens por nome, data, tipo ou tamanho |
| **Exibir** | Modos de visualização: ícones grandes, lista, detalhes, espaçamento compacto |
| **Três pontinhos (···)** | Comandos extras: Propriedades, Selecionar tudo, Abrir com |

### Barra de endereço

Mostra o caminho da pasta atual no formato de **migalhas de pão** (*breadcrumbs*): clicar em qualquer trecho (por exemplo, "Documentos" em Este Computador > Documentos > Relatórios) leva direto àquela pasta.

- Clicar na barra, ou usar **Ctrl + L** ou **Alt + D**, a transforma em campo de texto: dá para digitar ou colar um caminho (inclusive de rede, como \\servidor\pasta, ou endereço do OneDrive) e dar Enter. Há autocompletar.
- À esquerda ficam os botões de navegação: **Voltar** (retorna à última pasta visitada, não à pasta-mãe), **Avançar**, uma setinha que lista o **histórico** de pastas visitadas e **Acima** (vai à pasta de nível anterior, a pasta-mãe). **Backspace** também volta no histórico.

> ⚠️ Pegadinha: se você estava em C:\temp, entrou em C:\temp\ArquivoMorto\Documentos\Rejeitados e clicou em Voltar, retorna a **C:\temp** (a última visitada), e não a Documentos. Quem sobe um nível é o botão Acima.

### Caixa de pesquisa

Fica no canto superior direito. Por padrão busca na **pasta atual e em todas as subpastas**; encontra por nome, extensão e até pelo conteúdo de documentos, apoiada no **índice de pesquisa** do Windows (configurável: quais pastas indexar). Aceita filtros como data de modificação, tipo e tamanho. O atalho **Ctrl + E** coloca o cursor nela, e os resultados aparecem na área de conteúdo, com o termo em negrito.

> ⚠️ Pegadinha: para pesquisar em toda uma estrutura de pastas de uma só vez, selecione antes a **pasta de nível mais alto** que contém as demais; a busca só desce, nunca sobe.

### Para fixar

- Os botões de controle são Minimizar, Maximizar/Restaurar e Fechar; atalhos: Windows + setas e Alt + F4.
- O Explorador do Windows 11 tem abas (Ctrl + T abre; Ctrl + W fecha).
- Windows 10: faixa de opções expansiva com guias; Windows 11: barra de comandos compacta com os três pontinhos.
- Excluir manda o item para a Lixeira; Novo cria pasta (Ctrl + Shift + N); Renomear é F2.
- Barra de endereço em migalhas de pão; Ctrl + L ou Alt + D a selecionam para digitar caminhos.
- Voltar retorna à última pasta visitada; Acima sobe um nível.
- Pesquisa: pasta atual e subpastas, índice do Windows, filtros e Ctrl + E; para abranger tudo, selecione a pasta raiz.
