# ANALÍTICO

Balancear uma equação química significa escolher coeficientes que conservem a quantidade de átomos de cada elemento nos reagentes e nos produtos. O trecho recomenda começar por tentativas e completar algebricamente quando a inspeção deixar incógnitas interdependentes.

### Método por tentativas

Comece identificando elementos que aparecem em apenas uma espécie de cada lado. Se houver mais de uma opção, priorize o elemento com maior atomicidade (índice) nos compostos envolvidos. Transponha as quantidades como coeficientes e continue ajustando os demais elementos, conferindo ao final todos os átomos.

Mude coeficientes diante das fórmulas, nunca os índices internos: alterar índice modificaria a identidade química da substância. É permitido usar fração durante o cálculo; ao final, multiplique todos os coeficientes por um fator comum para obter os menores inteiros. O coeficiente 1 costuma ficar omitido. Reações com grupos poliatômicos conservados podem ser simplificadas contando o grupo como unidade, desde que ele permaneça igual nos dois lados.

Exemplo curto: H2S + Cl2 + H2O → H2SO4 + HCl. O enxofre define 1 para H2S e H2SO4; quatro oxigênios exigem 4 H2O. Há 10 H à esquerda, então coloque 8 em HCl, pois H2SO4 já contém 2. Restam 8 Cl à direita, logo são necessários 4 Cl2. Resultado: H2S + 4Cl2 + 4H2O → H2SO4 + 8HCl.

### Oxirredução e método misto

Em reações redox, elementos mudam número de oxidação, mas a contagem de átomos continua sendo a condição de balanceamento. Tentativas podem resolver muitos desses casos, embora não todos. Para equações com as espécies químicas já indicadas, o método misto permite aproveitar coeficientes simples definidos e resolver o restante como sistema algébrico.

Na etapa inicial, aplique tentativas até não ser possível determinar mais coeficientes independentemente. Depois nomeie os coeficientes restantes com incógnitas, escreva uma equação de conservação para cada elemento relevante e resolva o sistema, mantendo os coeficientes já obtidos. Deve haver equações suficientes para as incógnitas. Por fim, verifique todas as espécies e reduza os coeficientes a inteiros mínimos.

Exemplo redox: KMnO4 + FeCl2 + HCl → MnCl2 + FeCl3 + KCl + H2O. Tentativas fixam KMnO4, MnCl2 e KCl em 1, HCl em 8 e H2O em 4. O ferro aparece nos dois sais restantes, então ambos recebem a incógnita x. Conservando cloro: 2x + 8 = 2 + 3x + 1; logo x=5. Equação: KMnO4 + 5FeCl2 + 8HCl → MnCl2 + 5FeCl3 + KCl + 4H2O.

Essa estratégia pressupõe que a reação não esteja omitindo espécies desconhecidas, como H2O, H+ ou OH− quando necessárias. Se faltarem espécies, apenas coeficientes não bastam para representar corretamente a transformação; é necessário método que inclua o meio reacional e as espécies pertinentes.

### Para fixar
- Igualar átomos por coeficientes preserva as fórmulas químicas.
- Comece por elementos que apareçam em um composto de cada lado.
- Entre candidatos, priorize maior atomicidade; finalize os demais e confira tudo.
- Frações podem surgir; elimine-as multiplicando todos os coeficientes pelo mesmo número.
- Em redox, tentativas podem funcionar; se travarem, use incógnitas e conservação algébrica.
- Cada incógnita requer equações independentes suficientes.
- No exemplo KMnO4/FeCl2/HCl, conservação de Cl fornece 2x+8=3x+3, então x=5.
- Use método misto quando as espécies estiverem completas; ao fim, simplifique para inteiros mínimos.

# SINTÉTICO

- **Objetivo**: conservar o número de átomos de cada elemento dos dois lados, alterando somente coeficientes, nunca índices das fórmulas.
- **Tentativas**: escolha primeiro elemento presente em um composto de cada lado; se houver alternativas, use o de maior índice nos compostos para fixar coeficientes.
- **Fechamento**: ajuste os outros elementos e confira todos. Frações são permitidas provisoriamente; multiplique tudo para obter menores inteiros e omita coeficiente 1.
- **Exemplo**: H2S + Cl2 + H2O → H2SO4 + HCl fica H2S + 4Cl2 + 4H2O → H2SO4 + 8HCl.
- **Redox**: variação de NOX não muda a exigência de conservar átomos. Tentativas resolvem muitos casos, mas não todos.
- **Método misto**: preserve os coeficientes já definidos; atribua letras aos restantes, monte equações de conservação e resolva incógnitas.
- **Exemplo misto**: em KMnO4 + FeCl2 + HCl → MnCl2 + FeCl3 + KCl + H2O, fixam-se primeiro os coeficientes evidentes e a conservação de Cl resulta em x=5 para os dois sais de ferro.
- **Limite**: método por coeficientes supõe que todas as espécies necessárias estejam na equação; equações com espécies omitidas exigem consideração adicional do meio.
