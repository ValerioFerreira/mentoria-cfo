# ANALÍTICO

O logaritmo responde qual expoente transforma uma base em determinado resultado. Essa operação desfaz a potenciação e permite representar expoentes desconhecidos, além de simplificar cálculos por meio de propriedades algébricas.

### Definição e domínio

Para a>0, a diferente de 1, e x>0, log_a(x)=y equivale a a^y=x. A base a é o número elevado, x é o argumento e y é o expoente procurado. A positividade do argumento e as restrições da base são condições obrigatórias. Por exemplo, log_2(8)=3 porque 2³=8; log_2(1/4)=−2 porque 2^(−2)=1/4. Se log_x(243)=5, a conversão dá x^5=243, logo x=3, respeitadas as condições da base.

### Consequências imediatas

Da equivalência entre logaritmo e potência resultam identidades úteis: log_a(a)=1; log_a(1)=0; a^[log_a(x)]=x; log_a(a^x)=x. Além disso, log_a(x)=log_a(y) implica x=y, desde que x e y pertençam ao domínio. Elas permitem substituir uma forma pela outra para simplificar equações. A base não pode ser 1, pois suas potências não percorrem os valores positivos necessários para definir a operação.

### Bases usuais

Quando a base não aparece escrita, “log” representa normalmente a base 10, chamada decimal. A base e, constante irracional aproximada por 2,718, aparece como logaritmo natural e é indicada por ln; portanto, ln(x)=log_e(x). Não confunda ausência de base com base e: a notação distingue os dois casos.

### Propriedades operatórias

Para argumentos positivos e uma mesma base válida, o logaritmo de um produto é a soma dos logaritmos: log_a(xy)=log_a(x)+log_a(y). Para quociente, há subtração: log_a(x/y)=log_a(x)−log_a(y). Uma potência no argumento desce como fator: log_a(x^p)=p·log_a(x). No caso de potência na base, log_(a^p)(x)=(1/p)·log_a(x), quando as expressões são válidas. Não se deve confundir essa última regra com a potência do argumento: uma divide o logaritmo pela potência da base; a outra multiplica pelo expoente do argumento.

É comum combinar propriedades e fatorar números. Se log(2)=A e log(3)=B, então log(6)=A+B; log(9)=2B; log(1,5)=B−A; e log(36)=2A+2B, pois 36=2²·3². Também log(5)=1−A, pois 5=10/2. Essas decomposições dependem da base comum, aqui decimal, e do fato de log(10)=1. Em base 100, que é 10², log_100(2)=A/2.

As propriedades funcionam nos dois sentidos. Se log_2(x)=k, então log_16(x)=k/4 porque 16=2⁴. Se log_3(x)+log_3(y)+log_3(z)=4, a soma pode ser reunida como log_3(xyz)=4 e, pela definição, xyz=3⁴=81. Ao resolver, confira domínio e mantenha a mesma base em cada combinação.

### Para fixar
- Logaritmo é expoente: log_a(x)=y equivale a a^y=x.
- Base positiva e diferente de 1; argumento estritamente positivo.
- log_a(a)=1, log_a(1)=0 e log_a(a^x)=x.
- “log” sem base costuma indicar base 10; “ln” indica base e.
- Produto dentro do log vira soma; quociente vira diferença.
- Expoente no argumento vira fator multiplicador.
- Base elevada a p divide o logaritmo por p: log_(a^p)(x)=log_a(x)/p.
- Fatorar argumentos permite combinar logaritmos conhecidos; confira sempre a base comum.

# SINTÉTICO

- **Definição**: log_a(x)=y significa a^y=x; a>0, a≠1 e x>0.
- **Exemplos**: log_2(8)=3 e log_2(1/4)=−2, pois a definição é uma pergunta sobre expoentes.
- **Identidades**: log_a(a)=1; log_a(1)=0; a^[log_a(x)]=x; log_a(a^p)=p.
- **Bases**: log sem subscrito é decimal (base 10); ln designa a base e, aproximadamente 2,718.
- **Produto/quociente**: log_a(xy)=log_a(x)+log_a(y); log_a(x/y)=log_a(x)−log_a(y).
- **Potência**: log_a(x^p)=p·log_a(x); potência na base dá log_(a^p)(x)=log_a(x)/p.
- **Combinação**: se log2=A e log3=B, log36=2A+2B, pois 36=2²·3².
- **Reunião inversa**: soma de três logs de base 3 igual a 4 implica produto dos argumentos igual a 81.
