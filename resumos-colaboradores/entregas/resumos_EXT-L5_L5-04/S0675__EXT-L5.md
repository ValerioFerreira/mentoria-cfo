# ANALÍTICO

### Função, domínio e imagem
Uma função f:A→B associa a cada elemento do domínio A exatamente uma imagem em B. O domínio é o conjunto de partida, o contradomínio é o conjunto de chegada e a imagem reúne apenas os valores do contradomínio que são efetivamente atingidos. Portanto, imagem e contradomínio podem diferir. Elementos do domínio não podem ficar sem imagem nem ter duas imagens; já podem existir elementos do contradomínio que não recebem seta, e entradas diferentes podem compartilhar a mesma saída.

A lei de correspondência indica como calcular f(x). A função f(x)=2x associa cada x ao seu dobro. Para obter imagens, substitua x: se f(x)=4x e o domínio é {2,3,4,5}, a imagem é {8,12,16,20}. Uma função deve ser entendida pelos três elementos: domínio, contradomínio e lei. Algumas questões fornecem somente a expressão e pedem um valor; outras dependem dos conjuntos declarados.

### Gráficos e teste de função
Quando o domínio é finito, uma tabela ou diagrama pode listar pares (x,f(x)); no plano cartesiano cada par vira um ponto. Para domínios reais, costuma-se representar o conjunto de pontos como curva. Um gráfico representa uma função de x quando cada abscissa tem no máximo uma ordenada. O teste gráfico consiste em imaginar retas verticais: se alguma toca a curva em dois ou mais pontos, uma mesma entrada teria várias saídas e o gráfico não é função. Uma reta horizontal, por exemplo, representa função constante: entradas distintas têm a mesma imagem, o que é permitido.

### Domínio natural de uma expressão
Ao determinar o maior domínio real possível, procure restrições. Denominadores não podem ser zero; por isso, 1/x tem domínio R sem o zero. Raiz de índice par exige radicando não negativo: √(x+1) requer x≥−1. Se aparecem simultaneamente denominador variável e raiz par, as duas condições devem valer. Para f(x)=√(−2x+1)/(x+3), exige-se −2x+1≥0, portanto x≤1/2, e x+3≠0, portanto x≠−3. O domínio é o conjunto desses valores em conjunto.

Às vezes a raiz de expressão quadrática não restringe o domínio. Por exemplo, x²+2x+1=(x+1)²≥0 para todo real x; logo √(x²+2x+1) está definida em R. Procure outras restrições da lei além das duas mais comuns, como argumentos de logaritmos em tópicos específicos. Inclua a igualdade no radicando de raiz par, pois √0 existe nos reais.

### Injetividade
Uma função é injetora se entradas distintas sempre têm imagens distintas; equivalentemente, f(x)=f(y) implica x=y. A função x² em R não é injetora porque x=2 e x=−2 produzem 4. Já função afim com coeficiente angular não nulo é injetora. No gráfico, use retas horizontais: se qualquer reta horizontal cruza o gráfico no máximo uma vez, não há duas entradas com a mesma saída. Não confunda esse teste com retas verticais, que verificam se o gráfico é função. Uma função pode ser válida sem ser injetora.

### Para fixar
- Função: cada entrada do domínio tem exatamente uma saída.
- Domínio é partida; contradomínio é chegada; imagem contém os valores de chegada efetivamente atingidos.
- A lei f(x) calcula a imagem substituindo a entrada; f(x)=4x no domínio {2,3,4,5} tem imagem {8,12,16,20}.
- Reta vertical testa se o gráfico é função; reta horizontal testa injetividade.
- Denominador variável deve ser diferente de zero; radicando de raiz par deve ser ≥0.
- Injetora: x≠y implica f(x)≠f(y); x² em R falha pelo par 2 e −2.

# SINTÉTICO

- Função atribui exatamente uma imagem a cada elemento do domínio. O contradomínio é o conjunto de chegada; imagem é a parte efetivamente alcançada.
- Calcule imagens substituindo x na lei. Para f(x)=4x e domínio {2,3,4,5}, resulta {8,12,16,20}.
- Retas verticais testam se um gráfico é função; retas horizontais testam injetividade. Uma entrada pode compartilhar imagem, mas não pode ter duas imagens.
- Domínio: exclua zeros do denominador e imponha radicando ≥0 para raiz de índice par. Aplique todas as restrições simultaneamente.
- Injetividade exige saídas distintas para entradas distintas; x² em R não é injetora, pois f(2)=f(−2).
- Se a raiz envolve quadrado perfeito como (x+1)², seu radicando é não negativo para todo real x.
