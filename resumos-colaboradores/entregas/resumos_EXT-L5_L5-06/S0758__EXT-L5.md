# ANALÍTICO

### Soluções da igualdade entre senos

Para resolver sen α = sen β, considere duas famílias: ângulos congruentes, α = β + 2kπ, e ângulos suplementares, α = π − β + 2kπ, em que k é qualquer inteiro. Na primeira volta, são os dois pontos do ciclo com a mesma ordenada; somar 2kπ contempla todas as voltas positivas e negativas. Atenção: o período do seno é 2π, por isso não se substitui essa repetição por kπ.

Exemplo: sen x = sen(π/7). Então x = π/7 + 2kπ ou x = π − π/7 + 2kπ = 6π/7 + 2kπ. Para sen 2x = −√2/2, use −√2/2 = sen(−π/4). As duas famílias dão 2x = −π/4 + 2kπ ou 2x = π − (−π/4) + 2kπ = 5π/4 + 2kπ. Dividindo por 2: x = −π/8 + kπ ou x = 5π/8 + kπ.

### Redução de equações a sen x

Uma identidade pode transformar uma equação em uma quadrática na variável seno. Por exemplo, de 2 cos²x = 1 − sen x, use cos²x = 1 − sen²x. Obtém-se 2 sen²x − sen x − 1 = 0. Definindo y = sen x, resulta 2y² − y − 1 = 0, cujas soluções são y = 1 e y = −1/2. Cada igualdade deve ser resolvida pela regra das duas famílias. Para sen x = 1, há uma família coincidente x = π/2 + 2kπ. Para sen x = −1/2, pode-se usar o ângulo de referência −π/6: x = −π/6 + 2kπ ou x = 7π/6 + 2kπ.

### Restringir a um intervalo

Se o exercício pede raízes em um intervalo, primeiro obtenha as famílias gerais; depois escolha os valores inteiros de k que deixam x dentro dos limites. Em sen x = 0,5 no intervalo 0 < x ≤ 2π, as soluções são π/6 e 5π/6, cuja soma é π.

Em uma equação com argumentos distintos, como sen(4x) = sen(x+π), iguale argumentos pelas duas alternativas. A família congruente produz 4x = x+π+2kπ, logo x = π/3 + 2kπ/3. A suplementar produz 4x = π−(x+π)+2kπ, portanto x = 2kπ/5. Para o intervalo [0,π], a primeira família fornece π/3 e π; a segunda fornece 0, 2π/5 e 4π/5. São cinco raízes distintas.

### Para fixar

sen α = sen β implica α = β + 2kπ ou α = π − β + 2kπ. Se o argumento contém múltiplo de x, resolva a equação resultante antes de listar as famílias. Para intervalos fechados ou abertos, cheque cada candidato e respeite a inclusão das pontas.

# SINTÉTICO

- Para sen α = sen β, use α = β + 2kπ ou α = π − β + 2kπ, com k inteiro.
- As duas famílias correspondem aos ângulos com a mesma ordenada na circunferência; seno repete-se a cada 2π.
- Exemplo: sen x = sen(π/7) resulta em x = π/7 + 2kπ ou x = 6π/7 + 2kπ.
- Em sen 2x = −√2/2, escreva o lado como sen(−π/4), aplique as duas famílias e só então divida por 2.
- Use cos²x = 1 − sen²x para reduzir equações a uma quadrática em sen x.
- Cada solução obtida para sen x precisa ser convertida em sua família de ângulos.
- Para soluções num intervalo, primeiro derive a forma geral e depois selecione os inteiros k admissíveis.
- Em sen x = 0,5 para 0 < x ≤ 2π, as raízes são π/6 e 5π/6; a soma é π.
- Em equações sen A = sen B, aplique congruência e suplementaridade aos argumentos completos A e B.
- Confira se as soluções de famílias diferentes coincidem para não contar uma raiz duas vezes.
