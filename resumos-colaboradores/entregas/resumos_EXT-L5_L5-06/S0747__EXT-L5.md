# ANALÍTICO

### Definição e condições para existir

A função logarítmica associa a cada entrada x o valor f(x) = log_a(x), desde que a base a seja positiva e diferente de 1. Seu domínio natural é o conjunto dos reais positivos, enquanto sua imagem percorre todos os reais. A notação f(x) e y designa o mesmo valor de saída. É importante separar essas duas condições: a base precisa ser válida como base de logaritmo, e o argumento precisa ser estritamente positivo.

Quando a base é constante e válida, o cuidado recai sobre o argumento. Por exemplo, em f(x) = log_3(x − 8), exige-se x − 8 > 0, portanto x > 8. O ponto 8 fica de fora porque nele o argumento seria zero. Já em f(x) = log_(x−3)(8), o argumento constante 8 é positivo, mas a própria base depende de x. As condições x − 3 > 0 e x − 3 ≠ 1 produzem x > 3 e x ≠ 4. Assim, o domínio contém todos os valores acima de 3, exceto 4.

### Argumentos quadráticos e sinais

Se o argumento é um polinômio do segundo grau, deve-se resolver uma inequação estrita, não apenas encontrar suas raízes. Considere f(x) = log_2(x² − 9x + 14). A base 2 já satisfaz os requisitos. Fatorando o argumento, obtém-se (x − 2)(x − 7), que precisa ser maior que zero. Como o coeficiente de x² é positivo, a parábola fica positiva fora das raízes; seu domínio é x < 2 ou x > 7. Os extremos 2 e 7 são excluídos porque zeram o argumento.

Há uma inconsistência de sinal na expressão do domínio em uma linha do texto de origem, onde aparece x < −2. As raízes calculadas e a representação em intervalos indicam corretamente x < 2 ou x > 7. Para resolver, devem prevalecer as raízes e o estudo de sinais: entre 2 e 7 o produto é negativo; fora desse intervalo, positivo.

Quando tanto base quanto argumento dependem de x, as condições são resolvidas separadamente e depois intersectadas. Para log_(x+1)(x² − 5x − 14), a base requer x + 1 > 0 e x + 1 ≠ 1, isto é, x > −1 e x ≠ 0. O argumento fatorado, (x − 7)(x + 2), precisa ser positivo; isso ocorre para x < −2 ou x > 7. A interseção dessas condições deixa somente x > 7. A exclusão do zero não altera o resultado final, mas deve ser registrada ao montar o domínio.

### Imagem da função

Imagem é o conjunto de saídas y que podem ser produzidas por entradas pertencentes ao domínio. Para uma função logarítmica de base fixa válida, a imagem é R, ou seja, todos os números reais. Valores de saída podem ser negativos, iguais a zero ou positivos. Isso não significa que qualquer x seja permitido: o domínio continua submetido à positividade do argumento. Na questão com f(x) = log_2(x), por exemplo, o conjunto imagem é (−∞, +∞), e não um intervalo limitado ou o conjunto vazio.

Para não confundir domínio e imagem, pergunte: “quais x podem ser inseridos?” para determinar o primeiro; “quais resultados podem sair?” para o segundo. Em exercícios de domínio, faça uma lista das restrições da base e do argumento, resolva cada desigualdade com atenção às raízes e aos pontos excluídos e, por fim, tome a interseção. Em exercícios de imagem da função logarítmica padrão, reconheça que todos os reais podem ser obtidos.

### Para fixar

Base: a > 0 e a ≠ 1. Argumento: positivo. Uma desigualdade quadrática estrita exclui suas raízes; o sinal do polinômio determina em quais intervalos ele é admissível. Com restrições simultâneas, combine-as por interseção. Para f(x) = log_a(x), com base fixa válida, Im(f) = R.

# SINTÉTICO

- A função logarítmica de base a é f(x) = log_a(x), com a > 0 e a diferente de 1.
- A base deve permanecer positiva e não pode assumir o valor 1.
- O argumento do logaritmo precisa ser estritamente maior que zero.
- Em log_3(x − 8), o domínio é x > 8; o limite não entra porque produziria argumento nulo.
- Em log_(x−3)(8), a base impõe x > 3 e x ≠ 4.
- Em log_2(x² − 9x + 14), fatorar o argumento leva às raízes 2 e 7; o domínio é x < 2 ou x > 7.
- Se base e argumento dependem de x, resolva as condições separadamente e faça a interseção.
- Para log_(x+1)(x² − 5x − 14), a interseção das restrições resulta em x > 7.
- Uma linha do texto traz erro de sinal ao registrar x < −2; raízes e intervalos confirmam x < 2 ou x > 7.
- A imagem da função logarítmica de base fixa válida é todo R, podendo incluir resultados positivos, negativos e zero.
