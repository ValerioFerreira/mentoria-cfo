# ANALÍTICO

### Ideia da inequação

Para resolver tg x > a ou tg x < a, identifique primeiro os ângulos em que tg x = a e observe em que intervalos a tangente assume valores acima ou abaixo de a. A função tangente se repete a cada π radianos, e não a cada 2π, porque tg(x + π) = tg x. Assim, um intervalo de solução pode ser expresso com kπ, k inteiro. Os pontos x = π/2 + kπ devem sempre ficar excluídos: neles a tangente não está definida.

### Casos com sinal estrito

Para tg x > √3/3, a igualdade ocorre em π/6 e, após meia volta, em 7π/6. Em cada ramo crescente da tangente, os valores superiores ao limite aparecem entre o ângulo de igualdade e a assíntota vertical seguinte. A solução compacta é π/6 + kπ < x < π/2 + kπ, para todo k inteiro. As pontas são abertas porque a desigualdade é estrita e porque a tangente não existe na assíntota.

Como exemplo direto, tg x − 1 > 0 equivale a tg x > 1. O ângulo de referência é π/4; logo, π/4 + kπ < x < π/2 + kπ. A periodicidade π reúne os dois intervalos que poderiam ser escritos separadamente em uma volta completa.

Para tg x < 1, observe cada ramo no ciclo: em uma volta, os conjuntos incluem 0 ≤ x < π/4, π/2 < x < 5π/4 e 3π/2 < x ≤ 2π. Reunindo as repetições, uma expressão conveniente é π/2 + kπ < x < 5π/4 + kπ. A primeira extremidade é sempre aberta por corresponder a uma assíntota; a segunda fica aberta no caso estrito porque ali tg x = 1.

### Quando a desigualdade inclui igualdade

Se o sinal passa a ser ≥ ou ≤, inclua os pontos em que tg x = a, mas nunca inclua as assíntotas. Por exemplo, tg x ≥ √3/3 produz π/6 + kπ ≤ x < π/2 + kπ. A ponta correspondente ao limite é fechada; a ponta da assíntota continua aberta.

No caso tg x ≤ 0, as igualdades ocorrem nos múltiplos de π, e os ramos negativos terminam nesses pontos. Uma forma compacta da solução é π/2 + kπ < x ≤ π + kπ. Isso reúne, por alternância, os intervalos negativos da tangente e seus pontos finais onde ela vale zero. Para resolver questões, desenhe o ciclo ou marque assíntotas e zeros, confira o sentido do ramo e teste um ponto interior. Só então escolha os colchetes e generalize com kπ.

### Para fixar

Tangente tem período π e não existe em π/2 + kπ. Em tg x > a, cada solução fica do valor de igualdade até a assíntota seguinte, com extremos abertos; para ≥, feche apenas o extremo de igualdade. Em tg x < a, identifique os demais intervalos do ramo, lembrando de manter aberta qualquer assíntota. k percorre os inteiros.

# SINTÉTICO

- Para comparar tg x com um número a, localize primeiro a igualdade tg x = a no ciclo trigonométrico.
- A tangente tem período π; as famílias de soluções costumam usar kπ, com k inteiro.
- A função não existe em x = π/2 + kπ, portanto esses pontos são sempre excluídos.
- Em tg x > √3/3, o limite é atingido em π/6 e a solução é π/6 + kπ < x < π/2 + kπ.
- tg x − 1 > 0 equivale a tg x > 1; daí π/4 + kπ < x < π/2 + kπ.
- Para tg x < 1, uma forma geral é π/2 + kπ < x < 5π/4 + kπ.
- Ao trocar > por ≥, inclua o ponto onde a tangente iguala o limite; a assíntota continua aberta.
- Para tg x ≤ 0, a solução compacta é π/2 + kπ < x ≤ π + kπ.
- Desenhar os ramos, verificar as assíntotas e testar um ponto ajuda a evitar erros de sinal e de extremidade.
