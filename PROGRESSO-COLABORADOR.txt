SOBRE OS PDFs TEMPORÁRIOS
Os PDFs necessários foram enviados pelo Valério na branch descartável `docs-temp`. Nada de
`docs/` ou `pipeline/.cache` foi versionado na `bizus-exatas`. Terminado o trabalho, a
`docs-temp` pode ser apagada:
  git push origin --delete docs-temp
  git branch -D docs-temp
Observação: apagar a branch NÃO remove o conteúdo do histórico do Git no servidor
(commits continuam acessíveis por hash até o GC do GitHub); como os PDFs têm marca d'água
com nome/CPF, trate o repositório como privado.
